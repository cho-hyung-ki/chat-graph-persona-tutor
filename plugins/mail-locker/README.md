# Mail Locker Plugin - 메일이 오면 그 자리에서 사물함으로
> 인프라는 끝났다. 이제는 수용/거부만 하면 된다.
### 이 플러그인이 하는 일
1.  **메일 도착 시 그 자리에서 AI 연계**
    - 중요도 필터링: S/A/B/C급 자동 분류
    - 스팸 여부 확정: 90% 스팸이면 "버릴까요?" 확인
    - 요약-백업 자동: PDD 포맷으로 변환해 사물함에 저장
2.  **응답 초안 자동 생성**
    - AI가 답장 초안을 미리 만들어 둠
    - 사용자는 [확인] [수정] [보류] 만 누르면 됨
    - 전송 여부 확정은 사용자가 함 (AI가 멋대로 전송 안 함)
3.  **메일함 정리**
    - "메일함 정리해줘" 한 마디면
    - 중요도(S급 계약서/돈/가족은 절대 삭제 금지)에 따라 삭제 여부 결정
    - C급 스팸 300개 → "한 번에 삭제할까요? [Yes/No]"
4. **첨부 및 송신파일 정리**
    - 수신 및 송신 메일을 메일 내용과 링크(첨부파일의 위치로 연계)
    - 불필요 파일 이동-삭제 
5. **첨부파일 정리**
### 플러그인 원칙
This is not an App, This is a Plugin.
- 앱이 아니라, 기존 메일함 옆에 붙는 플러그인
- 그 자리에서 수용/거부 버튼이 보여야 함
